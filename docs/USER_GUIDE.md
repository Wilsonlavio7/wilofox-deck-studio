# User Guide

## Optional local profile

On the first visit, Wilofox asks how the user would like to be addressed and their activity: teacher, creator, presenter, student, or other. The user can also continue as a guest.

The profile:

- Personalizes the welcome message and dashboard.
- Is stored only in the current browser.
- Does not use a password or create an online account.
- Does not synchronize presentations between devices.
- Can be edited, changed to guest mode, or removed from **Settings > Local profile** without deleting presentations.

## Presentation library

The library allows users to create, import, search, filter, and organize presentations.

## Creating a presentation

Select **New** and define:

- Title
- Format
- Category
- Theme
- Estimated duration
- Production status

## Editor

The editor is divided into three main areas:

1. **Navigation:** sections and slides.
2. **Content workspace:** title, body, tags, notes, and visual resources.
3. **Settings:** format, theme, category, series, and production information.

## Visual resources

Slides can combine written content with diagrams, images, videos, and custom SVG resources.

## Presentation mode

Presentation mode provides:

- Progressive navigation
- Content and diagram focus modes
- Pointer and annotation tools
- Zoom and movement controls
- Section and slide progress

## Two-screen workflow

The audience sees the presentation while the presenter controls:

- Current and next slide
- Speaker notes
- Presentation timer
- Quick navigation
- Blackout mode

## Local persistence

Presentations and version history are stored locally with IndexedDB.

The optional display profile is stored separately as a local browser preference. Removing that profile does not remove decks. Clearing all site data may remove both preferences and presentations, so export important decks as JSON first.

## In-app quick guide

The **Quick Guide** provides search, three task-based entry points, expandable help sections, and frequently asked questions. It covers the recommended seven-step workflow, library organization, JSON-assisted content preparation, editing, presentation tools, two-screen OBS use, WebMCP, exports, backups, and common problems.

## Import and export

Use the application controls to import compatible presentation data or export the current work. Review imported content before presenting it.
