# User Guide

## Presentation library

The library allows users to create, import, search, filter, and organize presentations.

## Creating a presentation

Select **New** and define:

- Title
- Format
- Category
- Theme
- Estimated duration
- Production status

## Editor

The editor is divided into three main areas:

1. **Navigation:** sections and slides.
2. **Content workspace:** title, body, tags, notes, and visual resources.
3. **Settings:** format, theme, category, series, and production information.

## Visual resources

Slides can combine written content with diagrams, images, videos, and custom SVG resources.

## Presentation mode

Presentation mode provides:

- Progressive navigation
- Content and diagram focus modes
- Pointer and annotation tools
- Zoom and movement controls
- Section and slide progress

## Two-screen workflow

The audience sees the presentation while the presenter controls:

- Current and next slide
- Speaker notes
- Presentation timer
- Quick navigation
- Blackout mode

## Local persistence

Presentations and version history are stored locally with IndexedDB.

## Import and export

Use the application controls to import compatible presentation data or export the current work. Review imported content before presenting it.
