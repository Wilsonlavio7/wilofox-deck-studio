# Local Profile

Wilofox Deck Studio offers an optional local profile to make the workspace feel personal without introducing a misleading login screen.

## What it does

- Displays a personalized welcome message.
- Stores a display name and activity in the current browser.
- Provides a visible profile shortcut in the dashboard header.
- Supports teacher, creator, presenter, student, and other roles.
- Allows the user to continue in guest mode.

## What it does not do

- It does not create an online account.
- It does not use or store a password.
- It does not synchronize decks across browsers or devices.
- It does not protect presentations with authentication.

## Edit or remove the profile

1. Select the profile chip in the dashboard header or open **Settings**.
2. Select **Local profile**.
3. Change the display name or activity and select **Save profile**.
4. Select **Use guest mode** to remove personalization while keeping the preference saved.
5. Select **Delete local profile** to remove only the profile preference. Presentations remain intact.

## Data safety

Decks and history remain in IndexedDB, while the profile is a separate local browser preference. Export important presentations as JSON before clearing browser or site data.
