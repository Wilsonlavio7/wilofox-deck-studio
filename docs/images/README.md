# Project Images

Add clean project images to this folder using these filenames:

- `cover-github.png`
- `library.png`
- `editor.png`
- `presentation-mode.png`
- `control-panel.png`
- `webmcp-demo.png`

Recommended guidelines:

- Use PNG or WebP.
- Remove browser bookmarks and personal information.
- Use consistent dimensions.
- Keep each image below 2 MB when possible.
- Make sure the WebMCP demo image shows a real tool execution.
