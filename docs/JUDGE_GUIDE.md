## Two-minute verification

1. Open the live application in ChatGPT's in-app browser.
2. Confirm that the WebMCP status reports four active tools.
3. Ask the agent to read the current presentation.
4. Manually edit slide 2.
5. Ask the agent to read the presentation again.
6. Ask it to improve only slide 2.
7. Ask it to navigate to slide 2.

## Success criteria

- The application loads without authentication.
- The agent detects the latest human-edited state.
- Only the requested slide is changed.
- Other slides remain unchanged.
- The requested slide opens in the visible interface.
- Manual editing remains available without WebMCP.
